# 📦 Supply Chain Performance & Logistics Analytics Dashboard

## 📝 Project Overview
This project evaluates end-to-end supply chain operations, inventory management, logistics efficiency, and delivery lead times. Using the **DataCoSupplyChainDataset** raw data, Python for data preprocessing, MySQL for database querying, and Power BI for performance dashboarding, it tracks key operational KPIs to optimize supply chain delivery and logistics performance.

## 🛠️ Tools & Technologies Used
* **Dataset:** DataCo Supply Chain Dataset (`DataCoSupplyChainDataset` raw data)
* **Programming Language:** Python (Pandas, NumPy)
* **Database & Querying:** MySQL Workbench (`cleaned_supply_chain_data`)
* **Data Visualization:** Power BI (`Supply Chain Performance Dashboard`)
* **Development Environment:** Jupyter Notebook
